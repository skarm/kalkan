## Сбой VerifyData с буферами по 1 байту в SDK 2.0.13

Статус: открыт 2026-10-18
«сбой VerifyData с буферами по 1 байту в SDK 2.0.13».

Нужно сохранить минимальный воспроизводимый пример и определить, какие
выходные буферы вызывают сбой: `DataCapacity`, `InfoCapacity`, `CertCapacity`
по отдельности и в сочетании. Платформу, флаги, входной CMS, код возврата
и `GetLastError` зафиксировать при воспроизведении; причина пока не установлена.

Критерии закрытия:

- Воспроизведение запускается в отдельном процессе с SDK 2.0.13, чтобы возможное
  падение нативной библиотеки не прерывало весь набор тестов.
- Тот же CMS успешно проверяется с достаточными буферами.
- Обёртка безопасно обрабатывает минимальные размеры: увеличивает буферы
  в пределах лимита либо возвращает ошибку без непроверенных данных.
- Добавлен регрессионный тест и описано подтверждённое ограничение SDK
  или исправление обёртки.
